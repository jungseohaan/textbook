    무엇을 하는 앱인가

    교과서 한 권이 기획에서 학교 배포까지 거치는 8단계를 한 화면에서 보여 줍니다. 각 단계의 작업·담당·산출물을 정리하고, 단계 사이에 승인 게이트를 두어 다음 단계로 넘어가는 조건을 분명히 합니다. 편집장은 전체 진척을, 실무자는 자기 단계의 할 일을 확인합니다.

    화면 구성

    S1프로젝트 목록과목·학년별 교과서 카드. 현재 단계와 지연 여부를 한눈에 표시.
    S2공정 보드8단계 레일, 표준 일정 막대, 단계 상세. 이 프로토타입의 첫 탭.
    S3단계 상세작업 체크리스트, 담당자, 산출물, 게이트 조건과 반려 경로.
    S4산출물 보관함원고, 교정지 PDF, 심사본, 저작권 허락서를 버전별로 보관.
    S5게이트 승인승인권자가 조건을 확인하고 승인 또는 반려. 반려 사유는 이전 단계로 전달.
    S6공정 템플릿 관리검정·인정·디지털 교과서별 단계와 작업 목록을 편집.

    단계 상태 전이

    대기→ 진행→ 게이트 검토→ 승인
    게이트 검토→ 반려→ 지정 단계 재진행

    모든 작업이 끝나야 게이트 검토를 요청할 수 있습니다. 반려 시 rejectTo에 지정된 단계로 돌아가고, 그 뒤 단계는 대기로 초기화됩니다. 예: 검정 심사 수정·보완 지시 → 편집·검토 단계.

    기술 구성 제안

    • 프론트엔드React + TypeScript, 공정 레일과 일정 막대는 SVG 컴포넌트
    • 백엔드NestJS REST API, 게이트 승인 시 알림 이벤트 발행
    • 데이터PostgreSQL. 공정 템플릿은 JSON 컬럼으로 버전 관리
    • 파일S3 호환 스토리지. 교정지 PDF는 버전별 보존
    • 권한역할 기반(RBAC). 게이트 승인은 편집장·제작 관리자만
    • 알림마감 3일 전, 게이트 반려, 단계 전환 시 메일·메신저
